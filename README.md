## 🚀 Overview

This portfolio is a modern React-based web application built with a focus on immersive user experience (UX) and cinematic aesthetics. It features advanced scroll animations, interactive components, and a premium design system.

### Key Features
- **Immersive Interactivity**: Splash cursor effects, vector bridge interactions, and fluid animations.
- **Stack-based Project Display**: A custom-engineered scroll stack for showcasing selected works.
- **Parallax Storytelling**: Multi-layered parallax reveals and scroll-triggered content transitions.
- **Responsive Architecture**: Fully optimized for mobile, tablet, and desktop viewports.
- **Mechanical UX**: Integrated smooth-scrolling using Lenis for a tactile feel.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or bun

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/Manoj-alishala/portfolio-website.git
   cd portfolio-website
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   bun install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
